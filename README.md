# vigia

Monitorización de redes por sitio: Prometheus, Grafana, blackbox, SNMP e inventario de dispositivos,
generados a partir de un `site.yaml` por red y con el branding de cada sitio.

El paquete no contiene datos de ningún sitio: cada red vive en su propio repo (`site.yaml`, fichero de
entorno con los secretos y `assets/`) y fija la versión de `vigia` por tag.

En desarrollo.
